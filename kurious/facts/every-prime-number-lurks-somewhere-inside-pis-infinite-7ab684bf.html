Every Prime Number Lurks Somewhere Inside Pi's Infinite Digits

The endless, patternless digits of pi almost certainly contain every prime number ever discovered—and every one we'll ever find—hidden in plain sight.

Pi's digits stretch on forever without repeating: 3.14159265358979... and so on into infinity. Within this endless stream, mathematicians have found something remarkable. Look for the sequence 2, then 3, then 5, then 7—the first prime numbers. They're all there. Keep searching, and you'll find 11, 13, 17, and eventually any prime you can imagine. The digits of pi appear so random and evenly distributed that any finite sequence of numbers, including every prime, should appear somewhere. It's like having an infinite book that contains every possible sentence ever written. The primes aren't hiding deliberately—they emerge because infinity contains everything.
