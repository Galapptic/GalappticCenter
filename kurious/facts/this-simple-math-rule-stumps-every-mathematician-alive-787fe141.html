This Simple Math Rule Stumps Every Mathematician Alive

A problem so easy a child can understand it, yet so hard that even supercomputers testing billions of numbers can't prove it always works.

Pick any positive whole number. If it's even, divide by two. If it's odd, multiply by three and add one. Now repeat. Mathematicians have discovered that no matter which number you start with, you eventually reach one. Try it yourself: start with 7. You get 22, 11, 34, 17, 52, 26, 13, 40, 20, 10, 5, 16, 8, 4, 2, 1. Every single number tested—and we've checked quintillions of them—spirals down to one. Yet nobody can prove this always happens. The Collatz conjecture, named after German mathematician Lothar Collatz, remains one of mathematics' most frustrating unsolved problems precisely because it looks so deceptively simple.
